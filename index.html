Publications
Efficient reinforcement finetuning via adaptive curriculum learning
Taiwei Shi, Yiyang Wu, Linxin Song, Tianyi Zhou, Jieyu Zhao
Transactions on Machine Learning Research (TMLR)
project page / arXiv / poster / code / dataset

AdaRFT is a sample-efficient curriculum for reinforcement finetuning: during PPO/GRPO training it updates a target difficulty from recent rewards and samples problems near that target, so the model keeps training on problems that are challenging but solvable. Problem difficulty is estimated offline with pass@128 from Qwen2.5-Math-7B and validated against rubric-based GPT-4o ratings; this rollout-based difficulty gives greater learning gains than a judge-guided curriculum. Trained in veRL on DeepScaleR with Qwen2.5-Math-1.5B and Qwen2.5-7B, AdaRFT converges up to 2× faster and improves accuracy by 3–4 points on competition-level math benchmarks such as MATH-500 and AIME 24.

Coding Agent Trajectory Visualizer (VS Code extension)
VS Code Marketplace / project page / usage guide

A VS Code extension that reconstructs Claude Code and Codex sessions as one trajectory. It finds any past session by time, title, or project path; links each turn's model calls, tool calls and results, context compaction, and subagent activity; and captures the exact Claude Code API requests, so the assembled prompt and tool schemas behind every step can be inspected. Sessions stay on the local machine. I built it to study long-horizon coding-agent behavior, and it is published on the VS Code Marketplace.

Machine Learning Engineer Intern : TikTok Inc., Trust & Safety Team, San Jose, CA (May – Aug 2026)
Owned the post-training loop (data, SFT, RL, self-distillation, eval) for a video model that re-adjudicates the moderation system's own false positives. The task is asymmetric: recovering a wrongly flagged video is a gain, while releasing a real violation is an incident, so models were compared on precision, recall, and false-release rate together.

  • Data. Curated a million-scale decision-tree chain-of-thought corpus across 70 policies: selected the labeling LLM for each policy by its policy-specific performance, validated labels with sampled human review, and generated reasoning traces from the finalized labels.
  • SFT. Fine-tuned a 9B video multimodal LLM on the generated reasoning traces to 80% accuracy, and compared 20 data-mixture and verdict-weight settings on accuracy, precision, recall, and false-release rate to choose the starting checkpoints for RL and distillation.
  • RL. Adapted veRL to the proprietary model for 64-frame video inputs, and designed decision-tree-aligned step-level rewards with asymmetric penalties for GRPO training to improve reasoning reliability; audited reward, entropy, and response-length dynamics and read rollout reasoning during training.
  • Distillation. Applied RLSD and OPSD to multimodal video reasoning; on 20% of policies, precision and recall rose by up to 10 and 18 points over SFT while the false-release rate fell 4 points below the best SFT checkpoint.
